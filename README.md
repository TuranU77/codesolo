# Code Solo

Official website for Code Solo, a one-man indie game studio.

The site presents Code Solo and its apps in a playful retro desktop style:
small draggable windows, direct App Store links, dedicated privacy links, and
a compact contact area.

## Current Structure

- `index.html` is the main static page.
- `styles.css` contains the retro desktop/window styling and responsive layout.
- `script.js` contains the app data, window rendering, taskbar behavior, and dragging.
- `assets/logo.jpg` is the Code Solo logo.
- `privacy/*.html` are the dedicated privacy policy pages used by App Store entries.

## Important Links
